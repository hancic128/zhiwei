## Responsibilities

The maintainer is responsible for:
- **Technical direction**: Architecture decisions, technology choices
- **Release management**: Versioning, tagging, changelog
- **Security**: Vulnerability response, security policy
- **Community**: Code review, issue triage, documentation
- **Vision**: Ensuring alignment with project positioning

## Code Review

All code changes require review:
- **Bug fixes / Documentation**: One review approval
- **Features / Refactoring**: Maintainer review required
- **Security changes**: Maintainer-only review

## Becoming a Maintainer

This is currently a single-maintainer project. Contributors who consistently:
- Submit high-quality PRs
- Help review others' contributions
- Engage constructively in discussions
- Align with the project's vision

...may be invited to join as recognized contributors with limited merge rights.
